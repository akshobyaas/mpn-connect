Add a listing

The RCB admins add listings for now. Send them these details and your listing will go up on the directory.

Include

  • Full name
  • Business or profession
  • Listing type: I Can Help or I'm Looking For
  • Listing title
  • A short description
  • Category
  • Keywords or tags
  • WhatsApp number (optional; only if you're happy for members to message you)
  • How long the listing should stay up
